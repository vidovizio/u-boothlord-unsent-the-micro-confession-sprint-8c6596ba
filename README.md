This entry submits a two-part micro-confession: a `To:` line addressing "my father" and an unsent message about waiting to be asked how I am instead of being told what to fix. The program writes this exact text deterministically to `entry.txt`.

## Run it

```bash
node main.ts
```

Output appears at `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `./out/entry.txt`).
